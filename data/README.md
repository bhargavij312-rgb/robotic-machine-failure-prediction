# Dataset
Source: AI4I 2020 Predictive Maintenance Dataset
S. Matzka, UCI ML Repository, 2020, https://doi.org/10.24432/C5HS5C (CC BY 4.0)

To run:
Download ai4i2020.csv from https://www.kaggle.com/datasets/stephanmatzka/predictive-maintenance-dataset-ai4i-2020
and place it in this folder as data/ai4i2020.csv
